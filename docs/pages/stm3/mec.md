## Como usar o visualizador

| Ação | Como fazer |
| :--- | :--- |
| Girar o modelo | Arrastar com o botão esquerdo |
| Mover | Arrastar com o botão do meio, ou Shift + botão esquerdo |
| Aproximar | Roda do mouse |
| Buscar uma peça | Abrir o *Model Browser* no menu do visualizador |
| Tela cheia | Botão de tela cheia no canto do visualizador |
